# 5. From today's scheme

Ruled 2026-10-21: the task list is drawn from the deltas between the scheme we have and the model we want, once the
model is clear. This work must not stop other work that is underway, its pull requests are planned around that, and
the migration is managed carefully. On 2026-10-22 the plan's phases became a sweep of five iterations. Ruled
2026-11-02: a working issue tracking system on GitHub comes first, and the tooling follows. The cutover that began that
day brought GitHub's record to the model through commands the owner ran, ahead of the tooling, so the sweep's
iterations no longer set the order. Ruled the same day: #303 keeps only the design, and its build and rollout work is
in issues of its own, #365, #425, #426, #427, #428, #436, #437, #438, #439, #440, #441 and
David-Noble-at-work/personal#309. This section is rewritten to the rulings through 2026-11-03 and says which deltas
are closed, the ones the cutover closed in GitHub among them. The last rulings of 2026-11-03 rename threads
scenarios and give each team, and the user account, one Schedule project and one Scenario project in place of a
project per schedule and a project per thread. They also make Area, product or engineering, the way engineering work
is told from product work, put each account's issue fields in its model, and retire the old scheme's last three
pieces, the parent markers, the step and beat tables in issue bodies, and NobleFactor's kind labels, in GitHub that
day. The rulings of 2026-11-04 settle the questions #303 had left open, and the deltas they change say so.

## The line that protects the running sessions

What the sessions read: `star github schedule report` and `audit`, through the kind labels, the `**Feature:**` markers
and the step tables in the issue bodies until the old scheme retired on 2026-11-03; Start-Claude, keyed by a
schedule's issue number; and the label set. The report and the audit have read no `**Chore:**` marker since Chore was
retired on 2026-11-02. #350 to #354 named their parents, #347 and #348, with `**Feature:**` markers until the markers
came out on 2026-11-03: those two were chores with lanes until 2026-11-02 and are features since. The label set has
lost the chore label, removed from both accounts on 2026-11-02, and the `Epic:`, `Thread:` and `ClaudeJudgmentError:`
labels, removed from both accounts on 2026-11-03; NobleFactor's kind labels went the same day.

Anything added beside those breaks nothing: issue types, sub-issue links, projects, the model, its commands, tooling
that reads the new form before the old. What breaks a session is removing a label or a marker, replacing a step table
with rows, or renaming. The cutover made subtractive changes in GitHub before the switch, through the owner's commands
and not by pull request: the chore label removed on 2026-11-02, Lane renamed Step and the Next column deleted the same
day, and on 2026-11-03 the triage epics retired, the `Epic:`, `Thread:` and `ClaudeJudgmentError:` labels removed, and
the old scheme's last three pieces retired. Start-Claude read the chore label, so its removal reached Start-Claude; that
is #440.

Ruled 2026-11-03: the old scheme's last three pieces retire now, and the retirement was done in GitHub that day. The
parent markers and the schedule footers came out of 725 issue bodies, and 47 issues got the sub-issue parent their
marker named; where the marker and the link disagreed, the link stands. The step and beat tables in 14 Schedule and
Scenario issues gave way to a line naming the issue's project and its option there. The kind labels epic, feature,
task and bug left NobleFactor's 12 repositories, after 672 issues got the issue type their label named.
David-Noble-at-work keeps its type labels, which are its types.
