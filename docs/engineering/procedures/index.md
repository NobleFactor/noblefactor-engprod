# Engineering procedures

[Up: Engineering](../index.md)

Procedures explain how to satisfy the shared process. They do not grant authority, replace approvals or weaken standards.

The first review draft retains the [PR procedure](pull-request.md). The [clone-retirement procedure](clone-retirement.md) separates retirement mechanics from asset requirements. Open-branch, cleanup, deployment and recovery command procedures still need reconciliation before publication. Existing commands are not assumed to implement the newly approved decisions.

Compliance checks, GitHub configuration and first-/third-party tool choices are intentionally deferred. Do not replace a documented outcome with a claim that a tool “handles it.”
