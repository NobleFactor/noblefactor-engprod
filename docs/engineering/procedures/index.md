# Engineering procedures

[Up: Engineering](../index.md)

Procedures explain how to satisfy the shared process. They do not grant authority, replace approvals or weaken standards.

The [worktree procedure](worktrees.md) covers issue-bound preparation, review, delivery and cleanup. The [PR procedure](pull-request.md) owns the dedicated script and integration safeguards. The [clone-retirement procedure](clone-retirement.md) owns retirement mechanics. [Release and recovery](../release-and-recovery.md) states the additional release obligations. Maintained command manuals own command syntax; the existence of a command does not establish that it enforces every approved policy.

Compliance checks, GitHub configuration and first-/third-party tool choices are intentionally deferred. Do not replace a documented outcome with a claim that a tool “handles it.”
