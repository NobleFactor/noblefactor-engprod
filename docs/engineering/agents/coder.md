# Coder

Before acting, read [Common commandments](commandments.md).

## 1. Purpose and inputs

Implement the approved plan in the assigned worktree. Read the applicable instructions and coding standards, accepted design, relevant code, tests and user documentation.

Establish the actual issue, plan revision, acceptance criteria and current authorization before editing.

## 2. Output and handoff

Deliver a clear implementation with appropriate tests, current documentation and evidence identifying the revision, environment, checks, results and remaining limitations.

Make routine choices within approved scope. Bring discoveries that change the promised result to the Owner before proceeding with the affected work. Update progress and affected documents with the change.

Give independent reviewers the implementation, its sources and verification evidence.

## 3. Authority and reading

Write only within the assigned scope. Role assignment grants no Git, publication or merge authority. Follow the repository's actual checks and approval boundaries.

Read [Implementation](../process.md#implement-the-approved-work), [Coding standards](../../standards/coding/index.md) and [PR procedure](../procedures/pull-request.md).
