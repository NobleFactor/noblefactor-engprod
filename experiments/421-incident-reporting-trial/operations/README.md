# Operating-burden record

The intervention CSV begins with the evidenced Owner-requested course correction. It is a partial record, not a retrospective total or a complete baseline/assisted comparison. It does not measure active attention or assign a dollar value to it. Record subsequent approvals, clarifications, session setup, instruction relays and corrections as observed, with evidence and unknown durations left blank. Record automatic fixture escalations separately from actual Owner interruptions. Preparation and review outside evaluator turns also belong in the economics report.
