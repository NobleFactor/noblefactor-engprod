# Diagnostic request instruction

Run one diagnostic Codex model request to test the trial's measurement setup. Read the weekly usage meter immediately before and after, and capture the request's raw usage data. Count this request against the one-percentage-point weekly calibration budget.

Report the meter readings, token usage, and any limits on attributing usage or detecting retries. Stop if the meter is unavailable or the weekly usage increase reaches one percentage point. Treat this as a diagnostic, not a scored calibration case.
